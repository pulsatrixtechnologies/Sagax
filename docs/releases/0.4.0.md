Sagax 0.4.0 est une version d'essai de la lignée Pulsatrix (fork de base OpenMausBot 0.1.92). Ce n'est pas une version officielle d'OpenMausBot.

## Nouveautés

* **Mode organisation Perspicax**
  * Écran de lancement : **Pas de serveur** (Sagax solo) ou **Serveur** (l'adresse d'un serveur de votre organisation).
  * Connexion Pulsatrix dans le navigateur du système : clés d'accès (passkeys) et gestionnaires de mots de passe fonctionnent.
  * Mode serveur exclusif : l'application reste liée à ce serveur, avec la même interface que Sagax solo. Pour en sortir : Réglages > Général > Serveur > Changer.
  * Vos préférences vous suivent sur le serveur.
  * Fils privés.
  * Discussions de groupe avec des personnes.
  * La personne qui parle paie : son abonnement, sa clé dans Perspicax, puis la clé de l'organisation.
  * Les routines paient au nom de leur propriétaire.
  * Connecteurs Claude : un tour Claude garde les connecteurs claude.ai (Microsoft 365, GitHub, Gmail...) du compte de la personne qui parle.
* **Réglages courriel** : Réglages > Courriel configure l'envoi d'un serveur solo (SMTP, SendGrid ou Twilio), avec un courriel d'essai. Les secrets ne sont jamais réaffichés.
* **Mascotte de bureau**
  * La vraie chouette Sagax en 2D, et un aperçu 3D (désactivé par défaut).
  * Personnages : chouette, formes originales, Trombi.
  * Habillages avec effets, animations, barre d'énergie (le contexte du fil) et bulle de discussion.
* **Choix du modèle** : la pastille du modèle ouvre une fenêtre dédiée (fournisseurs, compte, modèles, effort et, en organisation, qui paie).
* **Fusion d'OpenMausBot 0.1.92** (en amont).
* **Emballage** : le zip Windows porte son propre nom (`PulsaBot-0.4.0-win-x64.zip`) ; éditeur et droits d'auteur : Pulsatrix Technologies Inc.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : l'application est maintenant signée (Developer ID, Pulsatrix) et notariée par Apple. Ouvrez le `.dmg` et glissez Sagax dans Applications. Le message « endommagé » de la 0.3.0 ne s'affiche plus.

**Windows** (x64) : lancez `PulsaBot-0.4.0-setup.exe`. L'installateur n'est pas signé : SmartScreen affiche un éditeur inconnu. Choisissez **Informations complémentaires**, puis **Exécuter quand même**. Une version portable est aussi offerte (`PulsaBot-0.4.0-win-x64.zip`).
