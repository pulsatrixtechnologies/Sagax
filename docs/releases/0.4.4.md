Sagax 0.4.4 regroupe les améliorations faites depuis 0.4.3.

## Nouveautés

* **Organisation : plugins, skills et serveurs MCP par personne**
  * **Réglages > Mes connexions** : connectez votre compte GitHub (device flow ou token collé) et ajoutez vos propres serveurs MCP (URL avec OAuth, URL avec token ou votre compte GitHub, ou commande lancée dans votre environnement serveur). Ils ne servent qu'à vos tours.
  * **Bibliothèque > Skills et Plugins** : marketplaces (dépôts privés compris), plugins et skills sur les bots que vous possédez ou gérez, avec une liste de marketplaces autorisés côté administrateur.
  * L'administrateur peut retirer cette autogestion personne par personne dans Perspicax ; ce qui est déjà en place continue de fonctionner.
* **Plus de moteurs sur un serveur d'organisation** : Grok Build, pi, Gemini CLI et Kimi Code, chacun payé avec les identifiants de la personne (connexion par code d'appareil pour Grok et Kimi).
* **Appel vocal plus rapide** : le délai entre la fin de votre phrase et la réponse du bot passe d'environ 4,5 s à 1,3 s (moteur gardé chaud pendant l'appel, fin de phrase détectée plus tôt, transcription envoyée dès qu'elle est stable).
* **Mascottes** : les formes Cœur et Triangle remplacent le haricot et le coin ; plus de lignes droites ni de flash avec l'habillage Holographique.
* **Correctifs**
  * Codex fonctionne de nouveau sur un serveur d'organisation.
  * Un bot créé par le Primary Bot d'une personne appartient à cette personne, et un accès en lecture seule (`use`) ne permet plus d'en créer.
* **Synchronisation OpenMausBot 0.1.95**
  * Section Épinglés dans la barre latérale, pour les conversations de tous les bots.
  * Indicateur de session ordinateur ou navigateur en direct dans les salles ; option pour rafraîchir les permissions d'une conversation.
  * Routines : date et heure dans le titre des exécutions, messages d'erreur détaillés.
  * Une relance de délégation reste dans la même conversation ; la mémoire d'un bot ne perd plus de note à la limite de taille.
  * Choix des outils par bot appliqué à tous les moteurs et serveurs MCP ; plusieurs correctifs de file d'attente pour l'ordinateur partagé.
* **Mises à jour techniques** : Electron 44, React 19.3, TypeScript 7, Vite 8 et les dépendances à jour ; Cua Driver 0.33.0.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.4.4-arm64.dmg` ou `Sagax-0.4.4-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.4.4-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.4.4-win-x64.zip` et `Sagax-0.4.4-win-arm64.zip`.

## English

* **Organization: plugins, skills and MCP servers per person**: Settings > My connections connects your GitHub account (device flow or pasted token) and adds your own MCP servers (URL with OAuth, URL with a token or your GitHub account, or a command run in your server environment), used for your turns only. Library > Skills and Plugins: marketplaces (private repos included), plugins and skills on bots you own or manage, with an admin list of allowed marketplaces. Admins can turn self-management off per person in Perspicax; what is already set up keeps working.
* **More engines on organization servers**: Grok Build, pi, Gemini CLI and Kimi Code, each paid with the person's own credentials (device-code sign-in for Grok and Kimi).
* **Faster voice calls**: the gap between the end of your sentence and the bot's reply drops from about 4.5 s to 1.3 s (engine kept warm for the call, earlier endpointing, transcript sent once stable).
* **Mascots**: Heart and Triangle shapes replace the bean and the wedge; no more straight lines or flash with the Holographic skin.
* **Fixes**: Codex works again on organization servers; a bot created by a person's Primary Bot belongs to that person, and read-only (`use`) access can no longer create one.
* **OpenMausBot 0.1.95 sync**: cross-bot Pinned threads section; live computer or browser session indicator in rooms and a refresh-permissions option for a thread; routine runs titled with date and time, with detailed errors; delegation follow-ups stay in the same thread; bot memory never drops a note at the size cap; per-bot tool selection enforced across every engine and MCP server; several shared computer queue fixes.
* **Under the hood**: Electron 44, React 19.3, TypeScript 7, Vite 8 and refreshed dependencies; Cua Driver 0.33.0.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
