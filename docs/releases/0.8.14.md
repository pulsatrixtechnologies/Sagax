Sagax 0.8.14 fiabilise le mode voix, simplifie Connect Apps et rafraîchit l'interface.

### Voix

* **Votre clé d'abord** : le mode voix utilise votre clé vocale personnelle en premier.
* **Erreur claire** : la vraie raison d'un refus est affichée, et la reprise se fait sans « Try again ».
* **iOS sur xAI** : la voix iOS passe par xAI, et le Markdown n'est plus lu à voix haute.

### Connect Apps

* **Sources** : réduit aux marketplaces.
* **GitHub** : une seule connexion, et le MCP GitHub reçoit enfin le jeton.
* **Onglet Pages** : nouvel onglet, et « My accounts » devient « Providers ».

### Interface

* **Police Geist** : Geist pour l'interface, Geist Mono pour le code.
* **Bulles** : couleur d'accent pour vos messages, gris pour le bot.
* **Menu +** : Loop et Goal sont retirés.
* **Pages** : les tableaux Markdown s'affichent dans les pages.

## Avant de mettre à jour

Rien à préparer à la main pour 0.8.14. Si vous hébergez Sagax vous-même, gardez une copie de vos données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English

Sagax 0.8.14 makes voice mode more reliable, simplifies Connect Apps and refreshes the interface.

### Voice

* **Your key first**: voice mode uses your personal voice key first.
* **Clear errors**: the real reason for a refusal is shown, and resuming works without "Try again".
* **iOS on xAI**: iOS voice goes through xAI, and Markdown is no longer read aloud.

### Connect Apps

* **Sources**: reduced to marketplaces.
* **GitHub**: a single connection, and the GitHub MCP now receives the token.
* **Pages tab**: a new tab, and "My accounts" becomes "Providers".

### Interface

* **Geist font**: Geist for the interface, Geist Mono for code.
* **Bubbles**: accent color for your messages, gray for the bot.
* **+ menu**: Loop and Goal are removed.
* **Pages**: Markdown tables render in pages.

## Before updating

Nothing to prepare by hand for 0.8.14. If you self-host, keep a copy of your data (`docs/self-hosting.md`) before you replace the image or the binary.
