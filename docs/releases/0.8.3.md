Sagax 0.8.3 laisse le propriétaire d'un bot partagé choisir qui paie ses réponses, donne plus d'autonomie à chaque membre et arrive pour la première fois sur npm.

## Bots partagés

* **Qui paie les réponses** : sur un serveur d'organisation, le propriétaire d'un bot choisit qui paie ses réponses, lui-même ou chaque personne qui lui écrit (Bot > Modèle). Un bot qui roule sur le modèle local du Mac de son propriétaire répond maintenant aussi aux autres.
* **Autonomie du membre** : sur le bureau et sur iOS, ce qui reste dans votre environnement est à vous. Vos propres bots se règlent sans administrateur (niveau d'approbation, modèle, navigateur, compétences, mémoire et plus).

## Interface

* **Vrais logos des apps** : le pied de la barre latérale montre les vrais logos de vos apps connectées.
* **Parcourir les bots** : un fil d'Ariane ramène à Connect Apps, avec le même filtre et la même position.
* **Réglages iOS** : la recherche est alignée avec le bouton Fermer et l'ouverture ne scintille plus (iPhone et iPad).

## npm

* **Premier paquet npm** : le serveur et la ligne de commande s'installent avec `npm install -g @pulsatrixtechnologies/sagax` (commande `sagax`).

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.8.3-arm64.dmg` ou `Sagax-0.8.3-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.8.3-setup.exe`. Non signée : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.8.3-win-x64.zip` et `Sagax-0.8.3-win-arm64.zip`.

## English

Sagax 0.8.3 lets the owner of a shared bot choose who pays for its replies, gives every member more autonomy and ships on npm for the first time.

* **Who pays for replies**: on an organization server, a bot's owner chooses who pays for its replies, the owner or each person who writes to it (Bot > Model). A bot running on its owner's local Mac model now answers other people too.
* **Member autonomy**: on desktop and iOS, what stays in your own environment is yours. Your own bots are set up without an administrator (approval level, model, browser, skills, memory and more).
* **Real app logos**: the sidebar footer shows the real logos of your connected apps.
* **Browse bots**: a breadcrumb takes you back to Connect Apps, with the same filter and position.
* **iOS Settings**: search lines up with the Close button and opening no longer flickers (iPhone and iPad).
* **First npm package**: the server and the command line install with `npm install -g @pulsatrixtechnologies/sagax` (command `sagax`).

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
