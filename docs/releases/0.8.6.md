Sagax 0.8.6 est une version large. Elle corrige l'écran noir sur iPhone, resserre la sécurité, garde un préfixe de prompt stable, et ajoute le clavardage, les bots, la mémoire, le panneau de développement et plusieurs commandes nouvelles.

### iPhone et iPad

* **Écran noir** : revenir d'une conversation ne laisse plus l'accueil noir. La maison reste visible.
* **Éditeur de bot** : créer et modifier un bot suit le même parcours que sur le bureau, sur iPhone et sur iPad.
* **Bulles** : dans un clavardage 1:1, la couleur des bulles suit le bot.
* **Page publiée** : l'app peut montrer un instantané de la page publiée.
* **Groupe** : le propriétaire d'un groupe ajoute des personnes, comme sur le bureau.
* **Maison et alarmes** : les deux utilisent la même carte d'accord.
* **Coffre** : 1Password et Link se règlent dans le coffre.
* **Routines** : l'éditeur et les routines de l'app restent alignés.
* **Me joindre** : le réglage est dans Réglages, section Bots.

### Clavardage

* **/loop** : une demande peut se répéter toute seule, au moins toutes les 5 minutes, au plus une fois par jour. Le statut et l'arrêt sont dans le compositeur.
* **/goal** : un objectif se pose dans un clavardage 1:1.
* **Niveau en cours de tour** : Ask, Edits ou Auto se change pendant que le bot travaille.
* **Résumé** : une longue réponse se lit en court, sur demande.
* **Bogue** : on signale un bogue depuis un clavardage. Rien ne part sans accord.
* **Pièces jointes** : les messages acceptent des pièces jointes binaires.
* **Envoi** : le compositeur n'envoie pas tant que le bot ne peut pas répondre. L'erreur ne s'affiche qu'une fois.
* **Commandes** : les commandes du bot sont dans le menu « / » et s'exécutent sur tous les moteurs.
* **Non-lus** : les messages non lus se comptent. Un avatar de personne réelle est refusé.
* **Salle** : on choisit un bot dans le panneau de la salle, au lieu d'ajouter le suivant.
* **Approbations** : une carte d'approbation se répond depuis n'importe quel bot qui vous appartient, y compris par les mots d'accord à la voix.

### Bots

* **Assistant v2** : « Créer un bot » ouvre un parcours guidé. L'identité, les règles (un effet par règle), puis les outils et les apps hors du chemin principal. Le récapitulatif reste compact.
* **Deux questions** : la création pose deux questions guidées.
* **Routines absentes** : un bot sans routine n'affiche plus de section Routines, seulement une ligne discrète.
* **Apps** : une page, un endroit par sujet, pour brancher les apps.
* **Me joindre** : WhatsApp Business se branche par la personne.
* **Agent externe** : un agent ACP personnalisé a son modèle et sa réflexion, par bot. Un adaptateur neutre transforme une fonction externe en bot.
* **Fenêtre de contexte** : Sagax lit la fenêtre publiée par le point de service.
* **Relève** : on choisit le modèle de relève, pas seulement le moteur.
* **Ordinateur du propriétaire** : un bot d'organisation peut rouler sur l'ordinateur de son propriétaire.
* **Droits du membre** : un membre agit sur ses bots avec ses propres droits. Il n'y a plus de carte d'admin pour ça.
* **Salles** : les bots d'une même personne n'ont plus de frontière entre eux. La visibilité reste au propriétaire. Pas de retour forcé à Ask.
* **Liste de tâches** : la liste de tâches du bot est distincte du journal de code.
* **Parcours** : un parcours montré une fois peut être sauvé en compétence.
* **Vidéo** : la vidéo est offerte sur tous les moteurs, sans le shell.
* **Ouverture de session** : Sagax peut s'ouvrir à l'ouverture de la session Mac.
* **Serveur MCP** : on ajoute un serveur MCP depuis une ligne de commande.
* **Mesure d'usage** : la mesure d'usage est au choix, avec un schéma fermé.
* **Préférences** : les préférences s'importent vers le bot principal.
* **Membres d'un groupe** : un seul parcours « Gérer les membres » pour les personnes et les bots.
* **Réalisations** : la page des réalisations est une page entière, pas une fenêtre modale.

### Sécurité

* **fast-uri** 3.1.9 et **cloudflared** 2026.10.3.
* **data_sql** : une lecture refuse un DELETE caché.
* **openai-chat** : un steer n'est plus perdu en silence.
* **VNC** : le mot de passe n'est plus lisible en loopback anonyme.
* **Chiffrement au repos** : la mémoire des bots, les pièces jointes et les journaux d'événements sont chiffrés.
* **Coffre** : une valeur déjà remplie ne se retrouve plus dans les prompts ni dans les journaux.
* **Visites du navigateur** : les visites du navigateur du bot sont signées.
* **Adresse collée** : coller une adresse n'en fait plus un serveur de commande.
* **OpenAPI** : les appels sont épinglés et les en-têtes sont scellés. Une personne peut avoir son connecteur.
* **Règle de produit** : une règle ne nomme un produit que tel que les serveurs le déclarent.
* **Reçus** : les reçus de données dont le titre commence par `notice:` s'affichent.
* **Signature de page** : une signature ratée n'empêche plus d'ouvrir la page.

### Mémoire et outils

* **Préfixe stable** : le prompt compact est le même sur chaque moteur. Les outils compacts valent pour tout Claude Code, pour que le cache de contexte serve. Une nouvelle conversation locale est servie par ce cache.
* **Sonde locale** : un essai de modèle local ne charge plus et ne génère plus pour `/messages`.
* **Dream** : une passe dream range les fichiers de mémoire.
* **Audience** : un fait capturé indique qui peut le lire. Une règle personnelle peut nommer qui a commencé le tour.
* **Mémoire d'entreprise** : elle se lit sur le chemin du tour, bornée comme MEMORY.md.
* **Mémoire déjà écrite** : le prompt compact retrouve la mémoire automatique déjà écrite.
* **Pont d'outils** : find_tool et use_tool lisent le catalogue Sagax. Le noyau d'un tour reste listé par son nom. use_tool est lu comme l'outil qu'il lance, à chaque couche de décision.
* **Rappel vectoriel** : une passe vectorielle locale est offerte après le rappel FTS5.

### Panneau de développement

* **Contrats** : taille du prompt et nombre de demandes de tirage.
* **Changements** : ce que le bot a fait sur une demande.
* **Connecteurs** : les doublons se replient, et Authenticate s'affiche.
* **Sorties** : les artefacts de la conversation s'ouvrent depuis le panneau.
* **Environnement** : actions du dossier, dépôt et branche.
* **Tâches** : durée, arrêt et tâches en parallèle.
* **Santé** : un rapport de santé peut rouler hors processus.
* **Journal d'actions** : le journal est chaîné en SHA-256 et s'exporte.

### Autres ajouts

* **Workflows YAML** : des workflows sans tour de modèle. Une approbation attend la réponse de la personne.
* **Condition de fin** : on peut empêcher un bot de terminer tant qu'une condition n'est pas vraie.
* **Graphiques** : la source et la date s'affichent sous un graphique. Un nombre pris dans une app nomme la pièce et la date.
* **Sauvegarde** : `sagax backup` et `sagax restore --verify`.
* **Coquille web et APK** : la coquille web est mise en cache, et un APK Android s'attache à la release.
* **Helm** : un chart Helm du serveur est ajouté.
* **Commandes headless** : appliquer une équipe, donner une tâche, attendre.
* **Pages** : audience, épingle, coédition, et mise à jour par le bot.
* **Documents** : les versions précédentes d'un artefact se gardent, et l'une d'elles se restaure.
* **Copie personnelle** : notes Chrome et dossiers prêtés.
* **Démo** : la suppression de compte se simule. Partager reste sur le bot épinglé.
* **Carte à usage unique** : Shop Pay et Link, sans paiement simulé.
* **Dette des cycles** : les imports circulaires entre le store client et le serveur sont cassés (rôle d'organisation, sélections de modèle, cache, permissions, pages, photos, approbations). Les familles i18n déjà lues restent couvertes : une clé nouvelle doit être lue.

## Avant de mettre à jour

Rien à préparer à la main pour la 0.8.6. Le chiffrement au repos s'applique à la mémoire des bots, aux pièces jointes et aux journaux d'événements. Si vous auto-hébergez, gardez une copie de vos données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English

Sagax 0.8.6 is a wide release. It fixes the black screen on iPhone, tightens security, keeps a stable prompt prefix, and adds chat, bots, memory, the dev panel, and several new commands.

### iPhone and iPad

* **Black screen**: going back from a chat no longer leaves the home black. The home stays visible.
* **Bot editor**: creating and editing a bot follows the same path as on the desktop, on iPhone and on iPad.
* **Bubbles**: in a 1:1 chat, bubble color follows the bot.
* **Published page**: the app can show a snapshot of the published page.
* **Group**: the owner of a group adds people, as on the desktop.
* **Home and alarms**: both use the same consent card.
* **Vault**: 1Password and Link are set in the vault.
* **Routines**: the editor and the app routines stay aligned.
* **Reach me**: the setting is in Settings, under Bots.

### Chat

* **/loop**: a request can repeat on its own, at least every 5 minutes, at most once a day. Status and stop are in the composer.
* **/goal**: a goal can be set in a 1:1 chat.
* **Level during a turn**: Ask, Edits, or Auto can be changed while the bot is working.
* **Summary**: a long reply can be read short, on request.
* **Bug**: a bug can be reported from a chat. Nothing is sent without agreement.
* **Attachments**: messages accept binary attachments.
* **Send**: the composer does not send while the bot cannot answer. The error shows once.
* **Commands**: the bot's commands are in the "/" menu and run on every engine.
* **Unread**: unread messages are counted. A real-person avatar is refused.
* **Room**: you pick a bot in the room panel, instead of adding the next one.
* **Approvals**: an approval card can be answered from any bot you own, including by voice yes-words.

### Bots

* **Assistant v2**: "Create a bot" opens a guided path. Identity, rules (one effect per rule), then tools and apps off the main path. The summary stays compact.
* **Two questions**: creation asks two guided questions.
* **No routines**: a bot with no routine no longer shows a Routines section, only a quiet line.
* **Apps**: one page, one place per subject, to connect apps.
* **Reach me**: WhatsApp Business is connected by the person.
* **External agent**: a custom ACP agent has its model and its reasoning, per bot. A neutral adapter turns an external function into a bot.
* **Context window**: Sagax reads the window published by the endpoint.
* **Failover**: you choose the failover model, not only the engine.
* **Owner's computer**: an organization bot can run on its owner's computer.
* **Member rights**: a member acts on their bots with their own rights. There is no admin card for that.
* **Rooms**: bots of the same person no longer have a boundary between them. Visibility stays with the owner. No forced return to Ask.
* **Task list**: the bot's task list is separate from the code journal.
* **Tour**: a tour shown once can be saved as a skill.
* **Video**: video is offered on every engine, without the shell.
* **Login**: Sagax can open when the Mac session opens.
* **MCP server**: an MCP server can be added from a command line.
* **Usage measure**: the usage measure is opt-in, with a closed schema.
* **Preferences**: preferences import onto the main bot.
* **Group members**: one "Manage members" path for people and bots.
* **Achievements**: the achievements page is a page, not a modal.

### Security

* **fast-uri** 3.1.9 and **cloudflared** 2026.10.3.
* **data_sql**: a read refuses a hidden DELETE.
* **openai-chat**: a steer is no longer dropped in silence.
* **VNC**: the password is no longer readable on anonymous loopback.
* **Encryption at rest**: bot memory, attachments, and event journals are encrypted.
* **Vault**: a filled value no longer shows up in prompts or journals.
* **Browser visits**: the bot browser's visits are signed.
* **Pasted address**: pasting an address no longer makes it a command server.
* **OpenAPI**: calls are pinned and headers are sealed. A person can have their own connector.
* **Product rule**: a rule names a product only as the servers declare it.
* **Receipts**: data receipts whose title starts with `notice:` are shown.
* **Page signature**: a failed signature no longer blocks opening the page.

### Memory and tools

* **Stable prefix**: the compact prompt is the same on every engine. Compact tools apply to all of Claude Code, so the context cache can serve. A new local conversation is served from that cache.
* **Local probe**: a local model probe no longer loads or generates for `/messages`.
* **Dream**: a dream pass tidies memory files.
* **Audience**: a captured fact records who may read it. A personal rule can name who started the turn.
* **Company memory**: it is read from the turn's path, bounded like MEMORY.md.
* **Memory already written**: the compact prompt finds automatic memory that was already written.
* **Tool bridge**: find_tool and use_tool read the Sagax catalog. A turn's core stays listed under its own name. use_tool is read as the tool it runs, on every decision layer.
* **Vector recall**: an optional local vector pass runs after FTS5 recall.

### Dev panel

* **Contracts**: prompt size and pull request counts.
* **Changes**: what the bot did on a pull request.
* **Connectors**: duplicates fold, and Authenticate is shown.
* **Outputs**: the conversation's artifacts open from the panel.
* **Environment**: folder actions, repository, and branch.
* **Tasks**: duration, stop, and parallel tasks.
* **Health**: a health report can run out of process.
* **Action journal**: the journal is chained with SHA-256 and can be exported.

### Other additions

* **YAML workflows**: workflows with no model turn. An approval waits for the person to answer.
* **Finish condition**: a bot can be kept from finishing until a condition is true.
* **Charts**: the source and the date show under a chart. A number taken from an app names the piece and the date.
* **Backup**: `sagax backup` and `sagax restore --verify`.
* **Web shell and APK**: the web shell is cached, and an Android APK is attached to the release.
* **Helm**: a Helm chart of the server is added.
* **Headless commands**: apply a team, give a task, wait.
* **Pages**: audience, pin, coediting, and update by the bot.
* **Documents**: earlier versions of an artifact are kept, and one of them can be restored.
* **Personal copy**: Chrome notes and lent folders.
* **Demo**: account deletion can be simulated. Share stays on the pinned bot.
* **One-time card**: Shop Pay and Link, with no simulated payment.
* **Cycle debt**: circular imports between the client store and the server are broken (organization role, model selections, cache, permissions, pages, photos, approvals). i18n families that are already read stay covered: a new key must be read.

## Before updating

Nothing to prepare by hand for 0.8.6. Encryption at rest applies to bot memory, attachments, and event journals. If you self-host, keep a copy of your data (`docs/self-hosting.md`) before you replace the image or the binary.
