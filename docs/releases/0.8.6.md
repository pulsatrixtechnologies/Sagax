Sagax 0.8.6 resserre la sécurité, stabilise le préfixe des prompts, et livre le pont d'outils, la mémoire dream, le panneau de développement, les manques ouverts et le remboursement de la dette des cycles.

* **iPhone, écran noir** : revenir d'une conversation ne laisse plus l'accueil noir. La maison reste visible.
* **Sécurité** : fast-uri 3.1.9 et cloudflared 2026.10.3. Une lecture data_sql refuse un DELETE caché. Un steer openai-chat n'est plus perdu en silence. Le mot de passe VNC n'est plus lisible en loopback anonyme. La mémoire des bots, les pièces jointes et les journaux d'événements sont chiffrés au repos. Le connecteur OpenAPI, l'adresse d'une commande MCP, la mémoire compacte et l'authentification du bot web sont resserrés. Les en-têtes OpenAPI sont scellés.
* **Préfixe stable** : le prompt compact est le même sur chaque moteur, et les outils compacts valent pour tout Claude Code, pour que le cache de contexte serve. Une nouvelle conversation locale est servie par ce cache.
* **Pont d'outils** : find_tool et use_tool lisent le catalogue Sagax. Le noyau d'un tour reste listé par son nom. use_tool est lu comme l'outil qu'il lance, à chaque couche de décision.
* **Mémoire dream** : une passe dream range les fichiers de mémoire. Un fait capturé indique qui peut le lire. Le prompt compact retrouve la mémoire automatique déjà écrite. La mémoire d'entreprise se lit sur le chemin du tour, bornée comme MEMORY.md.
* **Panneau de développement** : contrats (taille du prompt, nombre de demandes de tirage), changements sur une demande, connecteurs, sorties, environnement du dossier, et tâches en arrière-plan (durée, arrêt, parallèle).
* **Manques** : brief en lecture seule avec une file de revue, pont du catalogue, audience d'un fait, copie personnelle (notes Chrome et dossiers prêtés), sauvegarde et restauration vérifiée, coquille web et APK, rappel vectoriel après FTS5, journal d'actions chaîné en SHA-256, fin bloquée tant qu'une condition n'est pas vraie, sources et date sous un graphique, agent externe, commandes headless (équipe, donner une tâche, attendre).
* **Dette des cycles** : les imports circulaires entre le store client et le serveur sont cassés (rôle d'organisation, sélections de modèle, cache, permissions, pages, photos, approbations). Les familles i18n déjà lues restent couvertes : une clé nouvelle doit être lue.

## Avant de mettre à jour

Rien à préparer à la main pour la 0.8.6. Si vous auto-hébergez, gardez une copie de vos données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English

Sagax 0.8.6 tightens security, keeps the prompt prefix stable, and ships the tool bridge, dream memory, the dev panel, the open gaps, and the cycle-debt payoff.

* **iPhone, black screen**: going back from a chat no longer leaves the home black. The home stays visible.
* **Security**: fast-uri 3.1.9 and cloudflared 2026.10.3. A data_sql read refuses a hidden DELETE. An openai-chat steer is no longer dropped in silence. The VNC password is no longer readable on anonymous loopback. Bot memory, attachments, and event journals are encrypted at rest. The OpenAPI connector, a MCP command address, compact memory, and web bot authentication are tightened. OpenAPI headers are sealed.
* **Stable prefix**: the compact prompt is the same on every engine, and compact tools apply to all of Claude Code, so the context cache can serve. A new local conversation is served from that cache.
* **Tool bridge**: find_tool and use_tool read the Sagax catalog. A turn's core stays listed under its own name. use_tool is read as the tool it runs, on every decision layer.
* **Dream memory**: a dream pass tidies memory files. A captured fact records who may read it. The compact prompt finds automatic memory that was already written. Company memory is read from the turn's path, bounded like MEMORY.md.
* **Dev panel**: contracts (prompt size, pull request counts), changes on a pull request, connectors, outputs, the folder environment, and background tasks (duration, stop, parallel).
* **Gaps**: a read-only background brief with a review queue, the catalog bridge, a fact's audience, a personal copy (Chrome notes and lent folders), verified backup and restore, the web shell and APK, a vector pass after FTS5, a SHA-256 chained action journal, holding finish until a condition is true, source and date under a chart, an external agent, and headless commands (team, give a task, wait).
* **Cycle debt**: circular imports between the client store and the server are broken (organization role, model selections, cache, permissions, pages, photos, approvals). i18n families that are already read stay covered: a new key must be read.

## Before updating

Nothing to prepare by hand for 0.8.6. If you self-host, keep a copy of your data (`docs/self-hosting.md`) before you replace the image or the binary.
