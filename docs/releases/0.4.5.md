Sagax 0.4.5 regroupe les améliorations et correctifs faits depuis 0.4.4.

## Nouveautés

* **Notes de version dans l'application** : avant une mise à jour, Sagax vous montre ce qui change dans la nouvelle version (avec « Mettre à jour et redémarrer » ou « Plus tard »). Au premier lancement après la mise à jour, une fenêtre « Quoi de neuf » s'affiche une seule fois. Elle fonctionne aussi hors ligne.
* **Appel vocal : première réponse beaucoup plus rapide** : le moteur du bot est préparé dès que vous acceptez l'appel, donc le premier tour parlé n'attend plus son démarrage.
* **Grok et pi sur un serveur d'organisation** : ces deux moteurs sont maintenant utilisables sur un serveur d'organisation, avec l'abonnement Grok de chaque personne. Gemini CLI et Kimi Code y sont masqués.
* **Administration des connexions personnelles** : un administrateur d'organisation peut voir et révoquer les connexions MCP, GitHub et plugins d'une personne. Quand le droit « intégrations » d'une personne est désactivé dans Perspicax, ses connexions cessent de servir tout de suite (elles reprennent si le droit revient).
* **Réglages plus simples**
  * Un membre ne voit plus les réglages qu'il ne peut pas enregistrer.
  * Un seul réglage par défaut pour les nouveaux bots, et un seul contrôle « Works on ».
  * La voix, la génération d'images et les clés Boat sont dans Réglages.
  * Le panneau Bot est traduit dans toutes les langues.
* **Correctifs**
  * L'accès en lecture seule (`use`) à un bot est maintenant respecté : plus de Full access, plus de changement du modèle par défaut du bot, plus de partage.
* **Mise à jour technique** : Cua Driver 0.33.0 sur Linux.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.4.5-arm64.dmg` ou `Sagax-0.4.5-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.4.5-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.4.5-win-x64.zip` et `Sagax-0.4.5-win-arm64.zip`.

## English

* **Release notes in the app**: before an update, Sagax shows what changes in the new version (with "Update and restart" or "Later"). On the first launch after updating, a "What's new" window appears once. It also works offline.
* **Voice calls: much faster first reply**: the bot's engine is warmed up as soon as you accept the call, so the first spoken turn no longer waits for it to start.
* **Grok and pi on organization servers**: both engines are now usable on an organization server, with each person's own Grok subscription. Gemini CLI and Kimi Code are hidden there.
* **Managing personal connections**: an organization admin can see and revoke a person's MCP, GitHub and plugin connections. When a person's "integrations" right is turned off in Perspicax, their connections stop being used right away (they resume if the right comes back).
* **Simpler settings**: members no longer see settings they cannot save; one default for new bots and one "Works on" control; voice, image generation and Boat keys moved to Settings; the Bot panel is translated into every language.
* **Fixes**: read-only (`use`) access to a bot is now enforced: no Full access, no change to the bot's default model, no sharing.
* **Under the hood**: Cua Driver 0.33.0 on Linux.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
