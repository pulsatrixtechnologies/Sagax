Sagax 0.4.6 regroupe les améliorations et correctifs faits depuis 0.4.5.

## Nouveautés

* **Mode Simple ou Mode avancé** : dans Réglages, Apparence, l'interrupteur « Mode avancé » affiche les contrôles techniques. Il est éteint par défaut pour une installation neuve, un serveur solo et un membre d'organisation. Le propriétaire ou un admin d'organisation commence avec le mode avancé. Le choix est par personne, et un choix explicite gagne toujours sur le défaut du rôle. En mode Simple, ces contrôles sont cachés dans Réglages, le panneau du bot, les menus du compositeur et le sélecteur de modèle. L'approbation se résume à « Demander d'abord » et « Décider pour moi ». Ce qui est caché reste enregistré.
* **Moins de processeur au repos** : quand un bot se repose, le hibou de l'en-tête reste immobile au lieu de s'animer en continu. L'animation s'arrête aussi quand la fenêtre est cachée. Une fenêtre visible continue d'animer un bot qui travaille, même si elle n'est pas au premier plan.
* **Cloud personnel retiré** : le compte Cloud personnel, le déplacement vers le Cloud, le prêt de ce Mac et l'achat Cloud ne sont plus dans l'application. L'organisation Perspicax et les ordinateurs Boat restent en place.
* **Portail Admin retiré des Réglages** : l'entrée vers le portail d'administration hébergé n'apparaît plus. La connexion à une organisation Perspicax reste dans Réglages.
* **Sauvegardes `.sagaxbackup`** : les sauvegardes que Sagax écrit utilisent maintenant l'extension `.sagaxbackup`. Un fichier `.ombbackup` plus ancien s'importe encore.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.4.6-arm64.dmg` ou `Sagax-0.4.6-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.4.6-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.4.6-win-x64.zip` et `Sagax-0.4.6-win-arm64.zip`.

## English

* **Simple or Advanced mode**: in Settings, Appearance, the "Advanced mode" switch shows technical controls. It is off by default for a new install, a solo server, and an organization member. An organization owner or admin starts in Advanced mode. The choice is per person, and an explicit choice always wins over the role default. In Simple mode those controls are hidden in Settings, the bot panel, the composer menus, and the model picker. Approval is two choices: "Ask first" and "Decide for me". Hidden values stay saved.
* **Less CPU while idle**: when a bot is resting, the header owl stays still instead of animating continuously. Animation also stops when the window is hidden. A visible window keeps animating a bot that is working, even when the window is not in front.
* **Personal Cloud removed**: the personal Cloud account, moving to the Cloud, lending this Mac, and Cloud purchase are no longer in the app. Perspicax organizations and Boat computers stay.
* **Admin portal removed from Settings**: the entry to the hosted administration portal no longer appears. Joining a Perspicax organization stays in Settings.
* **`.sagaxbackup` backups**: backups Sagax writes now use the `.sagaxbackup` extension. An older `.ombbackup` file still imports.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
