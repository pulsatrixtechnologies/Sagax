Sagax 0.5.8 est un correctif.

## Correctif

* **Limite de 128 outils** : Les bots qui ont beaucoup d'outils (outils intégrés + applications connectées) ne s'arrêtent plus avec l'erreur de limite de 128 outils sur Grok et les autres modèles compatibles : les outils au-delà de la limite se chargent à la demande.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.5.8-arm64.dmg` ou `Sagax-0.5.8-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.5.8-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.5.8-win-x64.zip` et `Sagax-0.5.8-win-arm64.zip`.

## English

Sagax 0.5.8 is a hotfix.

* **128 tool limit**: Bots with many tools (built-in tools + connected apps) no longer stop with the 128 tool limit error on Grok and other compatible models: tools beyond the limit load on demand.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
