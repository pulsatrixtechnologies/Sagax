Sagax 0.4.7 réduit le coût au repos mesuré après 0.4.6.

## Nouveautés

* **Hiboux au repos** : un hibou qui respire, ou qui garde un visage non lu après la secousse, avance à environ 12 Hz au lieu du taux de l'écran. Le travail, le succès, la secousse, les clignements et les ailes restent à pleine cadence. Une image identique n'est pas réécrite.
* **Téléphone dans la barre** : un seul sondage pour le bouton et le menu. Il s'arrête quand la fenêtre est cachée et reprend quand elle revient. Un état identique ne redessine pas.
* **Pont desktop** : une réponse identique toutes les 20 s ne recrée plus l'objet, donc le compositeur ne se redessine pas pour rien.
* **Journal du serveur** : `server.log` tourne à 8 Mo et garde une copie `server.log.1`.
* **Relais de room** : le minuteur ne tourne que pendant qu'un transfert peut encore avancer. Il s'arrête quand l'arbre est au repos.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.4.7-arm64.dmg` ou `Sagax-0.4.7-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.4.7-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.4.7-win-x64.zip` et `Sagax-0.4.7-win-arm64.zip`.

## English

* **Resting owls**: an owl that is breathing, or holding an unread face after the shake, steps at about 12 Hz instead of the display rate. Work, success, the shake, blinks, and wings stay at full rate. An identical frame is not written again.
* **Sidebar phone**: one poll for the button and the menu. It stops while the window is hidden and runs again when the window returns. An unchanged snapshot does not redraw.
* **Desktop bridge**: an identical reply every 20 s no longer allocates a new object, so the composer does not redraw for nothing.
* **Server log**: `server.log` rotates at 8 MB and keeps one `server.log.1` copy.
* **Room handoff**: the timer runs only while a handoff can still move. It stops when the tree is idle.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
