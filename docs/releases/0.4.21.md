Sagax 0.4.21 rend le crabe lisible : des yeux carrés avec un shine, des pinces, des pieds, et un idle qui bouge comme Shape.

## Nouveautés

* **Crabe** : yeux 2x2 avec un shine, pinces, quatre pattes avec des pieds. Joyeux il plisse, endormi il ferme, il parle les yeux ouverts.
* **Crabe, idle** : un squash, un regard qui traîne, un pincement, un léger sway, les pattes qui tapent. Celebrate reprend la claque de Clawd avec des étincelles.
* **iOS** : le téléphone dessine le même sprite et le même idle CSS.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.4.21-arm64.dmg` ou `Sagax-0.4.21-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.4.21-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.4.21-win-x64.zip` et `Sagax-0.4.21-win-arm64.zip`.

## English

Sagax 0.4.21 makes the crab readable: square eyes with a shine, pincers, feet, and an idle that moves like Shape.

* **Crab**: 2x2 eyes with a shine, pincers, four legs with feet. Happy squints, sleepy closes, talking keeps the eyes open.
* **Crab, idle**: squash, a wandering look, a pinch, a slight sway, ticking legs. Celebrate is Clawd's clap with sparkles.
* **iOS**: the phone draws the same sprite and the same CSS idle.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
