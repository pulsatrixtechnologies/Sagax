Sagax 0.4.1 est une version corrective de Sagax 0.4.0.

## Correctif

* **L'application s'ouvre de nouveau** (macOS et Windows) : en 0.4.0, le démarrage appelait le compte infonuagique OMB, désactivé dans Sagax, et s'arrêtait avant d'ouvrir la fenêtre principale ; l'écran de démarrage tournait sans fin. Les versions publiées sont maintenant lancées pour vrai avant leur sortie (dossier de données neuf et copie d'un dossier 0.3.0).

* **Les modifications faites dans l'application de bureau sont de nouveau acceptées** : un en-tête interne mal renommé faisait refuser (403) certaines actions de l'application empaquetée, dont l'ouverture des flux de discussion.

## Aussi dans cette version

* **Appel vocal** : le bot se comporte comme au téléphone, et la voix ne lit plus la mise en forme Markdown.
* **Barre d'appel** en haut de la fenêtre.
* **Panneau du bot** : onglets Code et Activité.
* **Windows** : si le démarrage tarde, un écran l'indique avec **Ouvrir les journaux** et **Réessayer**.
* **iPhone** : l'application Sagax iOS est redessinée (accueil, connexion d'organisation, mode démo) ; elle est distribuée séparément.
* **Dépôt renommé** : `pulsatrixtechnologies/sagax` (l'ancienne adresse redirige ; les mises à jour suivent sans action).

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.4.1-arm64.dmg` ou `Sagax-0.4.1-x64.dmg` et glissez Sagax dans Applications. L'application est signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.4.1-setup.exe`, un seul installateur pour les deux. Il n'est pas signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.4.1-win-x64.zip` et `Sagax-0.4.1-win-arm64.zip`.

## English

Sagax 0.4.1 is a hotfix for Sagax 0.4.0.

* **Fix: the app opens again** on macOS and Windows. 0.4.0 called the OMB Cloud account at startup, which Sagax disables, and stopped before creating the main window, leaving the startup screen spinning. Release builds are now actually launched before shipping (fresh data folder and a copy of a 0.3.0 one).
* **Fix: desktop changes are accepted again**: a mis-renamed internal header made the packaged app's guarded actions (including opening chat streams) fail with 403.
* **Voice call**: the bot behaves like on the phone, and speech no longer reads Markdown formatting.
* **Call bar** at the top of the window.
* **Bot panel**: Coding and Activity tabs.
* **Windows**: a slow startup shows a screen with **Open logs** and **Retry**.
* **iPhone**: the Sagax iOS app is redesigned (onboarding, organization sign-in, demo mode); it ships separately.
* **Repository renamed** to `pulsatrixtechnologies/sagax` (the old address redirects; updates follow automatically).

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
