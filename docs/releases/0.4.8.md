Sagax 0.4.8 donne au bot le contrôle de la Local VM, et aligne le téléphone sur cet écran.

## Nouveautés

* **Local VM sur un serveur d'organisation** : un bot dont Works on est Local VM peut voir l'écran de cette VM, cliquer, taper et défiler. L'action reste dans le conteneur, sous l'utilisateur cua. Le bot n'obtient pas l'écran du Mac qui héberge Sagax. L'onglet Computer de l'organisation reste une image fixe et les boutons d'alimentation. Cette version du serveur et cette version de l'application desktop doivent être installées toutes les deux. Une application desktop trop ancienne dit de mettre Sagax à jour.
* **iPhone et iPad** : quand le téléphone est jumelé au serveur d'organisation et que Works on est Local VM ou This computer, Computer montre la même image fixe et les boutons Start, Pause, Stop et la mise en place. Take control reste sur l'environnement du serveur. Le téléphone n'envoie pas l'action qui conduit la VM. La rangée Details du desktop (disque, CPU, mémoire) n'est pas reprise sur le téléphone. Un serveur solo garde le visualiseur déjà en place.
* **Works on** : le choix a sa section dans More, juste après Access, sous le libellé Computer. Il n'est plus dans l'onglet Computer. Il est caché en mode Simple.
* **Apparence du bot** : au départ, le hibou et ses skins Common sont offerts. Une récompense verrouillée reste cachée jusqu'au déverrouillage. Shapes apparaît quand un compte Grok est lié. L'aperçu 3D est retiré du contrôle de style. Un style 3D déjà enregistré s'affiche comme le hibou plat.
* **Menu du compte** : Team map et Automations sont dans le menu de l'avatar. Help Center et Your phone n'y figurent plus. Le téléphone reste dans Settings et sur le rail replié.
* **Section vide** : le groupe sans équipe s'affiche Unassigned (Non assigné). L'identifiant enregistré ne change pas. Settings, General garde son nom.
* **Réglages** : les pastilles de portée sont retirées.
* **Hibou de bureau** : ouvrir le dialogue ne redimensionne plus la fenêtre, donc le hibou ne saute plus.
* **Actions du bot** : un bot appelle les mêmes actions que la personne connectée, dans les permissions de cette personne.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.4.8-arm64.dmg` ou `Sagax-0.4.8-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.4.8-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.4.8-win-x64.zip` et `Sagax-0.4.8-win-arm64.zip`.

## English

* **Local VM on an organization server**: a bot whose Works on is Local VM can see that VM's screen, click, type, and scroll. The action stays in the container, as user cua. The bot does not get the screen of the Mac that hosts Sagax. The organization Computer tab stays a still image and the power buttons. This server build and this desktop app both have to be installed. A desktop app that is too old says to update Sagax.
* **iPhone and iPad**: when the phone is paired to the organization server and Works on is Local VM or This computer, Computer shows the same still and the Start, Pause, Stop, and setup buttons. Take control stays on the server environment. The phone does not send the action that drives the VM. The desktop Details row (disk, CPU, memory) is not on the phone. A solo server keeps the viewer it already had.
* **Works on**: the choice has its own More section, right after Access, labelled Computer. It is no longer on the Computer tab. It is hidden in Simple mode.
* **Bot look**: at the start, the owl and its Common skins are offered. A locked reward stays hidden until it unlocks. Shapes appears when a Grok account is linked. The 3D preview is removed from the style control. A stored 3D style draws as the flat owl.
* **Account menu**: Team map and Automations are in the avatar menu. Help Center and Your phone are no longer there. The phone stays in Settings and on the collapsed rail.
* **Empty section**: the group with no team displays as Unassigned. The stored id does not change. Settings, General keeps its name.
* **Settings**: the scope pills are removed.
* **Desktop owl**: opening the dialog no longer resizes the window, so the owl does not jump.
* **Bot actions**: a bot calls the same actions as the signed-in person, within that person's permissions.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
