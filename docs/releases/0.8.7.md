Sagax 0.8.7 est une version de correctifs. Elle remet à plat les modes de fils, garde le modèle local sur le moteur pi, isole les workflows par personne et renforce le lien avec la console d'organisation.

### Clavardage

* **Fils, mode « une seule conversation »** : plus aucun fil ne s'affiche à part. Le détail d'une sous-tâche s'ouvre sur place.
* **Fils, mode barre latérale** : le repli fonctionne et les fils restent affichés.
* **Alignement** : les lignes de fils sont alignées.

### Bots

* **Modèle local sur pi** : un bot réglé sur un modèle local ne bascule plus en silence vers un modèle infonuagique. Chaque personne a son propre dossier pi pour ce tour.
* **Outils cherchés** : un appel d'outil d'un catalogue cherché est jugé comme l'outil réel par les règles de la personne et de l'organisation.
* **Tâches et brief de fond** : un serveur plus ancien n'affiche plus d'erreur rouge dans les réglages du bot.
* **Connect Apps** : la portée reste visible sur tous les onglets, « N connected » s'ouvre d'un clic, et la page d'un plugin s'ouvre dans son onglet.

### Sécurité

* **Lien avec la console** : chaque appel fait au nom d'une personne porte son propre jeton.
* **Workflows** : sur un serveur partagé, chaque personne a ses propres workflows. Un enregistrement refusé ne laisse plus de fichier effacé.
* **Dépendances** : undici 7.30.1 et zod 4.6.6.

## Avant de mettre à jour

Rien à préparer à la main pour 0.8.7. Si vous hébergez Sagax vous-même, gardez une copie de vos données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English

Sagax 0.8.7 is a fix release. It straightens out the thread modes, keeps local models on the pi engine, isolates workflows per person, and hardens the link with the organization console.

### Chat

* **Threads, "One conversation" mode**: no thread shows on its own anymore. A subtask's detail opens in place.
* **Threads, sidebar mode**: collapsing works and threads stay listed.
* **Alignment**: thread rows line up.

### Bots

* **Local model on pi**: a bot set to a local model no longer switches silently to a cloud model. Each person gets their own pi folder for that turn.
* **Searched tools**: a tool call from a searched catalog is judged as the real tool by the person's and the organization's rules.
* **Tasks and background brief**: an older server no longer shows a red error in bot settings.
* **Connect Apps**: the scope stays visible on every tab, "N connected" opens on click, and a plugin's page opens in its own tab.

### Security

* **Console link**: every call made on behalf of a person carries that person's own token.
* **Workflows**: on a shared server, each person has their own workflows. A refused save no longer leaves an erased file.
* **Dependencies**: undici 7.30.1 and zod 4.6.6.

## Before updating

Nothing to prepare by hand for 0.8.7. If you self-host, keep a copy of your data (`docs/self-hosting.md`) before you replace the image or the binary.
