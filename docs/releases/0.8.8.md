Sagax 0.8.8 donne plus de portée aux bots. Un bot peut proposer une page publique et passer un appel téléphonique, les Routines se rangent en dossiers, et un membre fait plus de choses sans attendre un admin.

### Bots

* **Pages publiques** : un bot peut proposer une page dans la conversation directe. Vous la publiez ou la refusez, aussi depuis iOS.
* **Appels téléphoniques** : un bot peut passer un appel téléphonique depuis la conversation directe.
* **Outils débloqués pour les membres** : `vm_exec`, l'ordinateur partagé, l'ajout de fichiers et l'ajout d'un serveur MCP ne demandent plus un admin quand l'action reste dans l'environnement du membre. Les outils non classés n'attendent plus un admin.
* **Outils débloqués pour les moteurs** : navigateur et ordinateur pour xAI, Mistral et MiniMax, recherche web pour Codex en tour invité, et Data, Messages et recherche web joignables là où ils manquaient.
* **Modèles d'un membre** : le nouveau bot d'un membre démarre sur un modèle que ce membre peut utiliser, et l'assistant de création lui laisse le choisir. Un modèle coupé sur le compte qui paie affiche un message clair.
* **Ask pendant un tour** : passer à Ask pendant un tour s'applique dès le prochain appel d'outil.

### Routines

* **Dossiers** : les Routines d'un bot se rangent en dossiers, sur desktop et iOS.

### Interface

* **Achievements** : page Achievements refaite : catégories en filtre, cartes compactes.
* **iOS** : l'app compile de nouveau (HomeKit, alarmes, bulle du bot).

## Avant de mettre à jour

Rien à préparer à la main pour 0.8.8. Si vous hébergez Sagax vous-même, gardez une copie de vos données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English

Sagax 0.8.8 gives bots more reach. A bot can propose a public page and place a phone call, Routines can be sorted into folders, and a member does more without waiting for an admin.

### Bots

* **Public pages**: a bot can propose a page in the direct conversation. You publish or decline it, on iOS too.
* **Phone calls**: a bot can place a phone call from the direct conversation.
* **Tools unlocked for members**: `vm_exec`, the shared computer, attaching files and adding an MCP server no longer wait for an admin when the action stays in the member's own environment. Unclassified tools no longer wait for an admin.
* **Tools unlocked for engines**: browser and computer for xAI, Mistral and MiniMax, web search for Codex in a guest turn, and Data, Messages and web search reachable where they were missing.
* **A member's models**: a member's new bot starts on a model that member can run, and the creation wizard lets them pick it. A model turned off on the paying account shows a clear message.
* **Ask during a turn**: switching to Ask during a turn applies from the next tool call.

### Routines

* **Folders**: a bot's Routines can be sorted into folders, on desktop and iOS.

### Interface

* **Achievements**: the Achievements page is redone: categories as a filter, compact cards.
* **iOS**: the app builds again (HomeKit, alarms, bot bubble).

## Before updating

Nothing to prepare by hand for 0.8.8. If you self-host, keep a copy of your data (`docs/self-hosting.md`) before you replace the image or the binary.
