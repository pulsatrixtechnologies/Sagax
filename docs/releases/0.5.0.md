Sagax 0.5.0 lance des agents de code dans le nuage et les suit dans le panneau du bot.

## Nouveautés

* **Agents de code** : lancez Cursor, Claude ou Codex dans le nuage ; une section Code du panneau suit chaque agent lancé.
* **Terminal** : un widget terminal dans la conversation, avec des adaptateurs de ressources génériques.
* **Vidéo** : vidéos et YouTube s'affichent directement dans la conversation.
* **Ultracode** : un mode d'effort Ultracode, avec une interface violette.
* **Mascottes** : les avatars de la barre latérale suivent le pointeur, se penchent et réagissent au toucher.
* **iOS** : plus d'animation d'intro du bot ; réglages accessibles en haut de la liste des bots.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.5.0-arm64.dmg` ou `Sagax-0.5.0-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.5.0-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**.

## English

Sagax 0.5.0 launches cloud coding agents and tracks them in the bot panel.

* **Coding agents**: launch Cursor, Claude or Codex in the cloud; a Coding section in the panel tracks each launched agent.
* **Terminal**: an in-chat terminal widget, with generic resource adapters.
* **Video**: videos and YouTube play inline in chat.
* **Ultracode**: an Ultracode effort mode with purple UI chrome.
* **Mascots**: sidebar avatars follow the pointer, lean and react to taps.
* **iOS**: no more bot intro animation; settings reachable from the top of the bot roster.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
